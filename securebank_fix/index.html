Fraud Detection Engine
5 Active SQL Trigger Rules

Each rule is a MySQL AFTER INSERT trigger. PHP inserts the transaction — MySQL detects fraud and saves alerts automatically.

💸

Rule 1 — Large Transaction

Any single transaction above ₹50,000 triggers a HIGH severity fraud alert saved to the database immediately.

⚡

Rule 2 — Rapid Velocity

5+ transactions on one account within 60 seconds triggers a HIGH alert — detects bot and scripted attacks.

📍

Rule 3 — Location Anomaly

Same account used in two different cities within 10 minutes — physically impossible travel detected automatically.

🏧

Rule 4 — ATM Daily Limit

Total ATM withdrawals exceeding ₹1,00,000 in a single day triggers a MEDIUM severity alert.

🔑

Rule 5 — Account Takeover

A transaction within 10 minutes of a password change is flagged HIGH — possible account takeover.

📧

Instant Email Alert

When any rule fires, an email notification modal appears and the alert is permanently saved to MySQL.
